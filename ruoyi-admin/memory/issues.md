# 已知问题与解决方案记忆

## 工具链问题

### 中文文件名处理
- `write_to_file` 写入含中文+空格的文件名时，实际文件可能省略空格
  - 例: "常见问题 FAQ.md" → "常见问题FAQ.md"
  - 例: "CI-CD 配置.md" → "CI-CD配置.md"
- **对策**: 避免中文文件名中使用空格，或用 `find` 确认实际文件名

### replace_in_file 中文匹配
- 对含中文内容的文件，`replace_in_file` 可能匹配失败（编码/隐藏字符差异）
- **对策**: 匹配失败后直接用 `write_to_file` 整体重写

### ls 命令中文路径
- `ls` 访问含中文路径时可能出现编码错误
- **对策**: 改用 `find` 命令

## 项目问题

- `src/test/` 目录为空，无任何测试代码
