## 简介

本快速入门指南旨在帮助新开发者快速搭建 RuoYi 项目的本地开发环境。RuoYi（若依）是一套全部开源的快速开发平台，基于 Spring Boot 3 开发的轻量级 Java 快速开发框架，可用于所有的 Web 应用程序，如网站管理后台、网站会员中心、CMS、CRM、OA 等。

## 系统要求

在开始之前，请确保您的系统满足以下要求：

- **JDK 版本**: JDK 17 或更高版本
- **内存**: 至少 4GB RAM
- **磁盘空间**: 至少 1GB 可用空间
- **网络**: 稳定的互联网连接
- **操作系统**: Windows / Linux / macOS
- **数据库**: MySQL 5.7+ 或 8.0+

## 项目克隆

首先，您需要克隆项目到本地开发环境：

```bash
git clone https://github.com/ChenLiyan-GT/RuoYi-Vue.git
cd RuoYi-Vue
```

## 环境准备

### 1. 安装 JDK 17

确保您的系统已安装 JDK 17 或更高版本：

```bash
java -version
javac -version
```

如果未安装，请从 Oracle 官网或 OpenJDK 下载并安装。

### 2. 安装 Maven

项目使用 Maven 作为构建工具。您可以使用以下方式安装：

#### 方法一：通过 SDKMAN! 安装（推荐，Linux/macOS）
```bash
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install maven 3.9.12
```

#### 方法二：手动安装
从 [Maven 官网](https://maven.apache.org/download.cgi) 下载并配置环境变量。

### 3. 验证 Maven 安装
```bash
mvn -v
```

## 数据库和缓存服务启动

项目依赖 MySQL 数据库。

### 初始化数据库

1. 创建数据库：
```sql
CREATE DATABASE `ry-spring` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

2. 导入初始化脚本：
```bash
mysql -u root -p ry-spring < sql/ry_20260319.sql
```

或者使用其他 MySQL 客户端工具导入 `sql/ry_20260319.sql` 文件。

### 配置数据库连接

编辑 [`application-druid.yml`](../../../ruoyi-admin/src/main/resources/application-druid.yml) 文件，配置数据库连接信息：

```yaml
spring:
    datasource:
        druid:
            master:
                url: jdbc:mysql://localhost:3306/ry-spring?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
                username: root
                password: 1234
```

请根据实际情况修改用户名和密码。

## 项目导入到 IDE

### IntelliJ IDEA 导入

1. 打开 IntelliJ IDEA
2. 选择 "File" -> "Open..."
3. 浏览到项目根目录并选择
4. 选择 "Import project from external model"
5. 选择 "Maven" 并点击 "Next"
6. 配置 Maven 设置（建议使用默认设置）
7. 点击 "Finish"

IDEA 会自动下载依赖并导入项目。

## 构建和运行项目

### 构建项目

在项目根目录下执行：

```bash
mvn clean install
```

或者跳过测试：
```bash
mvn clean install -DskipTests
```

### 运行应用程序

有两种方式启动应用：

#### 方式一：使用 Maven 命令
```bash
cd ruoyi-admin
mvn spring-boot:run
```

#### 方式二：直接运行 Java 主类
在 IDE 中找到 [`RuoYiApplication.java`](../../../ruoyi-admin/src/main/java/com/ruoyi/RuoYiApplication.java) 文件，右键选择 "Run"

#### 方式三：运行打包后的 JAR
```bash
java -jar ruoyi-admin/target/ruoyi-admin.jar
```

## 故障排除

### 常见问题及解决方案

#### 1. 端口冲突
如果 80 端口被占用，可以在 [`application.yml`](../../../ruoyi-admin/src/main/resources/application.yml) 中修改端口配置：
```yaml
server:
  port: 8080
```

#### 2. 数据库连接失败
检查数据库服务是否正常运行：
```bash
# 查看 MySQL 服务状态
systemctl status mysqld  # Linux
# 或
net start | findstr MySQL  # Windows
```

检查数据库配置是否正确，用户名密码是否匹配。

#### 3. 内存不足
增加 JVM 堆内存：
```bash
export JAVA_OPTS="-Xms2g -Xmx4g"
mvn spring-boot:run
```

#### 4. Maven 构建失败
清理并重新构建：
```bash
mvn clean install -U
```

#### 5. IDE 导入问题
- 确保 Maven 已正确配置
- 检查 JDK 版本设置（必须为 JDK 17+）
- 重新导入项目：File -> Invalidate Caches / Restart

#### 6. 静态资源加载失败
检查 `ruoyi-admin/src/main/resources/static` 目录是否包含完整的前端资源文件。

#### 7. 验证码不显示
检查是否配置了正确的验证码类型（math 数字计算 或 char 字符验证）：
```yaml
shiro:
  user:
    captchaType: math
```
