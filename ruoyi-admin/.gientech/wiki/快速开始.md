## 简介

本快速入门指南旨在帮助新开发者快速搭建 RuoYi 项目的本地开发环境。RuoYi（若依）是一套基于 Spring Boot 3 开发的轻量级 Java 快速开发框架，全部开源，可用于所有的 Web 应用程序，如网站管理后台、网站会员中心、CMS、CRM、OA 等。系统支持移动客户端访问，并会陆续更新一些实用功能。

**核心特性**：
- 用户管理、部门管理、岗位管理、菜单管理、角色管理
- 字典管理、参数管理、通知公告、操作日志、登录日志
- 在线用户监控、定时任务调度、代码生成、系统接口
- 服务监控、缓存监控、在线构建器、连接池监视

演示地址：http://ruoyi.vip  
文档地址：http://doc.ruoyi.vip

## 系统要求

在开始之前，请确保您的系统满足以下要求：

- **JDK 版本**: JDK 17 或更高版本
- **构建工具**: Maven 3.6+
- **数据库**: MySQL 5.7+ 或 8.0+
- **内存**: 至少 2GB RAM（推荐 4GB 以上）
- **磁盘空间**: 至少 1GB 可用空间
- **网络**: 稳定的互联网连接
- **操作系统**: Windows / Linux / macOS

## 项目克隆

首先，您需要克隆项目到本地开发环境：

```bash
git clone https://github.com/ChenLiyan-GT/RuoYi-Vue.git
cd RuoYi-Vue
```

## 环境准备

### 1. 安装 JDK 17

确保您的系统已安装 JDK 17 或更高版本：

```bash
java -version
javac -version
```

如果未安装，请从 Oracle 官网或 OpenJDK 下载并安装。

### 2. 安装 Maven

项目使用 Maven 作为构建工具。您可以使用以下方式安装：

#### 方法一：通过 SDKMAN! 安装（推荐）
```bash
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install maven 3.9.12
```

#### 方法二：手动安装
从 [Maven 官网](https://maven.apache.org/download.cgi) 下载并配置环境变量。

### 3. 验证 Maven 安装
```bash
mvn -v
```

## 数据库和缓存服务启动

项目依赖 MySQL 数据库。首次使用前需要初始化数据库。

### 初始化数据库

1. 创建数据库并设置字符集：

```sql
CREATE DATABASE IF NOT EXISTS ry-spring DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE ry-spring;
```

2. 导入初始化 SQL 脚本：

```bash
# 导入核心数据库脚本
mysql -u root -p ry-spring < sql/ry_20260319.sql

# 导入定时任务脚本（可选）
mysql -u root -p ry-spring < sql/quartz.sql

# 导入 Work 管理相关脚本（可选）
mysql -u root -p ry-spring < sql/work_management.sql
mysql -u root -p ry-spring < sql/work_menu.sql
```

### 配置数据库连接

编辑 `ruoyi-admin/src/main/resources/application-druid.yml` 文件，配置数据库连接信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ry-spring?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
    username: root
    password: 你的数据库密码
```

## 项目导入到 IDE

### IntelliJ IDEA 导入

1. 打开 IntelliJ IDEA
2. 选择 "File" -> "Open..."
3. 浏览到项目根目录 `RuoYi-Vue` 并选择
4. 选择 "Import project from external model"
5. 选择 "Maven" 并点击 "Next"
6. 配置 Maven 设置（建议使用默认设置）
7. 点击 "Finish"

IDEA 会自动下载依赖并导入项目。

## 构建和运行项目

### 构建项目

在项目根目录下执行：

```bash
mvn clean package -DskipTests
```

或者使用编译检查：

```bash
mvn clean compile
```

### 运行应用程序

有三种方式启动应用：

#### 方式一：使用启动脚本（推荐）

**Windows 系统**：
```bash
ry.bat
```
然后选择菜单 [1] 启动应用。

**Linux 系统**：
```bash
./ry.sh start
```

#### 方式二：直接运行 Java 主类
在 IDE 中找到 `RuoYiApplication.java` 文件，右键选择 "Run"

#### 方式三：使用 Maven 命令
```bash
mvn spring-boot:run -pl ruoyi-admin
```

#### 方式四：运行打包后的 JAR
```bash
java -jar ruoyi-admin/target/ruoyi-admin.jar
```

## API 调用示例

让我们通过一个简单的 API 调用来验证环境配置是否正确。

### 获取验证码

```bash
curl -X GET "http://localhost:80/captcha/captchaImage"
  -H "accept: */*"
```

预期响应（Base64 编码的图片数据）：

```json
{
  "code": 200,
  "msg": "操作成功",
  "captcha": true,
  "uuid": "xxx-xxx-xxx",
  "img": "data:image/gif;base64,..."
}
```

### 用户登录

```bash
curl -X POST "http://localhost:80/login"
  -H "Content-Type: application/x-www-form-urlencoded"
  -d "username=admin&password=admin123&code=xxx&uuid=xxx"
```

预期响应：

```json
{
  "code": 200,
  "msg": "登录成功",
  "token": "xxx"
}
```

### 获取用户信息

```bash
curl -X GET "http://localhost:80/system/user/profile"
  -H "Authorization: Bearer xxx"
```

## 故障排除

### 常见问题及解决方案

#### 1. 端口冲突

如果 80 端口被占用，可以在 `application.yml` 中修改端口配置：

```yaml
server:
  port: 8080  # 修改为其他端口
```

#### 2. 数据库连接失败

检查数据库服务是否正常运行：

```bash
# Windows
net start MySQL80

# Linux
systemctl status mysql
```

查看数据库连接配置是否正确，确认用户名、密码、数据库名无误。

#### 3. 内存不足

增加 JVM 堆内存，编辑启动脚本 `ry.bat` 或 `ry.sh`：

```bash
JVM_OPTS="-Xms512m -Xmx1024m -XX:MetaspaceSize=128m -XX:MaxMaxMetaspaceSize=512m"
```

或命令行启动时指定：

```bash
java -Xms512m -Xmx1024m -jar ruoyi-admin.jar
```

#### 4. Maven 构建失败

清理并重新构建：

```bash
mvn clean install -U
```

或跳过测试：

```bash
mvn clean package -DskipTests
```

#### 5. IDE 导入问题

- 确保 Maven 配置正确（settings.xml）
- 检查 JDK 版本设置为 17
- 重新导入项目（Maven -> Reload Project）
- 清除 IDE 缓存并重启

#### 6. 验证码无法显示

检查 `CaptchaConfig` 配置，确认 Kaptcha 相关依赖已正确引入。

#### 7. 静态资源 404

检查 `ruoyi-admin/src/main/resources/static` 目录下是否存在前端资源文件。
