## 2. 产品概述

### 2.1 产品定位

本系统是面向企业各部门的作业分配与工时管理平台，基于 RuoYi-Vue 框架开发，实现作业分割、工时管理、进度安排、员工级别匹配、智能分配等核心功能。

### 2.2 目标用户

| 用户角色 | 职责描述 | 核心需求 |
| --- | --- | --- |
| 系统管理员 | 系统配置与规则管理 | 配置作业阶段模板、级别规则、部门参数 |
| 部门经理 | 部门作业与人员管理 | 查看部门负载、调整分配、审批作业 |
| 项目经理 | 作业创建与进度跟踪 | 创建作业、分配员工、监控进度 |
| 普通员工 | 作业执行与进度汇报 | 查看个人作业、更新进度、工时填报 |

### 2.3 核心价值

1. **资源优化**：通过智能算法减少员工空闲时间，提升资源利用率 20%+
2. **精准匹配**：基于级别和技能的员工 - 作业匹配，降低错配风险
3. **效率提升**：自动化工时分配，减少手动计算时间 80%+
4. **灵活配置**：支持部门级作业阶段自定义，适应不同业务流程

| 功能 ID | 功能名称 | 功能描述 | 优先级 |

**数据字段**：

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| job_id | Long | 是 | 作业 ID（主键） |
| job_no | String | 是 | 作业编号（唯一） |
| job_name | String | 是 | 作业名称 |
| dept_id | Long | 是 | 所属部门 ID |
| template_id | Long | 是 | 使用的阶段模板 ID |
| total_workload | Decimal | 是 | 总工时（小时） |
| status | Integer | 是 | 状态（0 未开始 1 进行中 2 已完成 3 已取消） |
| start_date | Date | 否 | 计划开始日期 |
| end_date | Date | 否 | 计划结束日期 |
| actual_end_date | Date | 否 | 实际结束日期 |
| create_by | Long | 是 | 创建人 ID |
| create_time | DateTime | 是 | 创建时间 |

**工时计算逻辑**：

```
阶段工时 = 总工时 × 阶段占比
所需人员 = CEIL(阶段工时 / 标准人效 / 工作天数)
标准人效 = 6 小时/天（可配置）
```

#### 3.3.3 作业分配

**功能描述**：为作业阶段分配员工。

**功能点**：

| 功能 ID | 功能名称 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| ASN-001 | 员工推荐 | 根据级别、技能、负载推荐合适员工 | P0 |
| ASN-002 | 手动分配 | 手动选择员工进行分配 | P0 |
| ASN-003 | 智能分配 | 一键智能分配最优员工 | P1 |
| ASN-004 | 分配调整 | 调整已分配的员工 | P1 |
| ASN-005 | 分配历史 | 查看分配变更记录 | P2 |

**智能分配算法**：

```
优先级评分 = 负载分 × 0.4 + 匹配分 × 0.4 + 效率分 × 0.2

负载分 = 1 - (当前负载 / 最大负载)
匹配分 = 级别匹配度 × 0.6 + 技能匹配度 × 0.4
级别匹配度 = 1 / (1 + |员工级别 - 要求级别|)
技能匹配度 = 匹配技能数 / 要求技能总数
效率分 = 历史作业平均完成度

选择评分最高的员工
```

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 | 说明 |
| --- | --- | --- |
| 页面响应时间 | < 2 秒 | 90% 的请求 |

- 集成 RuoYi Shiro 认证授权
