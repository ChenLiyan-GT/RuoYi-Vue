# 需求登记

## 需求概述

**需求名称**：部门员工作业安排机能

**业务背景**：基于 RuoYi-Vue 框架，实现各部门员工的作业分配、工时管理、进度安排的综合管理系统。

## 核心功能范围

### 1. 作业分割与工时管理

- 作业阶段定义：需求分析、基本设计、内部设计、开发、单体测试、结合测试、综合测试、上线
- 作业阶段可配置：不同部门可裁剪或追加阶段
- 工时自动分配：输入总工时，按阶段占比自动分配
- 人员需求计算：根据阶段工时和员工级别自动计算所需人员
- 作业匹配规则：
  - 需求分析 - P9 以上员工
  - 基本设计 - P6 以上员工
  - 内部设计 - P6 以上员工
  - 开发 - P4 以上员工
  - 测试 - P3 以上员工

### 2. 员工职能和级别管理

- 职能分类：前端、后端、测试、产品、项目管理等
- 级别体系：P1~P10 共 10 个级别
- 员工技能标签：支持多技能标签管理
- 员工状态跟踪：空闲、工作中、过载

### 3. 智能作业分配

- 空闲员工优先分配
- 作业不满员工负载均衡
- 技能匹配度评估
- 级别匹配度验证

### 4. 部门作业阶段管理

- 部门级作业阶段模板
- 阶段模板保存与复用
- 阶段占比配置
- 部门特殊规则配置

## 关键利益相关者

- **系统管理员**：配置作业阶段模板、员工级别规则
- **部门经理**：查看部门作业分配、调整工时分配
- **项目经理**：创建作业、分配员工、跟踪进度
- **普通员工**：查看个人作业、更新进度

## 预期价值

1. **提升资源利用率**：通过智能分配减少员工空闲时间
2. **优化人员配置**：基于级别和技能的精准匹配
3. **提高管理效率**：自动化工时分配和进度跟踪
4. **支持灵活配置**：适应不同部门的作业流程差异

## 技术约束

- **后端框架**：基于 RuoYi-Vue 的 Java Spring Boot 架构
- **前端框架**：Vue.js + Element UI
- **数据库**：MySQL
- **权限管理**：集成 RuoYi 现有的 Shiro 权限体系
- **编码规范**：遵循 RuoYi 项目的代码规范和分层架构

## 需求优先级

| 优先级 | 功能模块 | 说明 |
| --- | --- | --- |
| P0 | 员工管理基础功能 | 员工信息、级别、职能管理 |
| P0 | 作业阶段配置 | 阶段定义、占比配置、模板管理 |
| P0 | 作业创建与分配 | 作业创建、工时分配、员工匹配 |
| P1 | 智能分配算法 | 空闲员工识别、负载均衡 |
| P1 | 进度跟踪 | 作业进度更新、工时统计 |
| P2 | 报表分析 | 部门负载分析、员工效率统计 |

## 验收标准概览

1. 能够创建、编辑、删除作业阶段模板
2. 能够录入员工信息并设置级别和职能
3. 输入总工时可自动计算各阶段工时
4. 能够根据级别规则匹配合适员工
5. 能够识别空闲员工并优先分配
6. 能够查看作业进度和工时统计
7. 支持部门级配置隔离
